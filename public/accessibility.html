Accessibility statement

This accessibility statement applies to the NHS App Quick Setup Guide at app-guide-8vm0.onrender.com .

The guide provides information about using NHS App services in multiple languages. We want as many people as possible to be able to use this website.

Using this website

We aim to make this website accessible so that visitors can:

  • Navigate using a keyboard.
  • Read content using a screen reader.
  • Zoom in without losing important content.
  • Use the website on mobile devices.
  • Choose from the available translations.

How accessible this website is

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

A complete accessibility assessment has not yet been recorded in this statement. We cannot currently confirm that every part of the website meets WCAG 2.2 AA.

Known accessibility limitations

Accessibility testing is ongoing. We are reviewing keyboard navigation, screen-reader compatibility, colour contrast, text resizing, translated content and right-to-left language presentation.

Specific issues identified during testing will be documented here, along with planned improvements.
